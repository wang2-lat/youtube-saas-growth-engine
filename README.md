## <a id="english"></a>English

### Overview
A content flywheel system that converts low-view YouTube tutorials into high-revenue SaaS customers by targeting search intent instead of viral views. Harvests customer pain points, creates targeted tutorials, and optimizes them as permanent search assets.

### Features
- Customer pain harvesting from communities, onboarding emails, support tickets, and YouTube comments
- Tutorial creation system using customer's exact language and solving one specific problem per video
- SEO optimization for Google search (not YouTube algorithm) with keyword placement and structured chapters
- Support ticket to public tutorial conversion workflow
- AI citation optimization for ChatGPT and Google AI Mode visibility
- Content calendar generation from recurring customer questions
- YouTube analytics tracking focused on search traffic (63% search, 26% from Google)
- Long-tail keyword targeting for niche technical problems

### Installation
```bash
pip install -r requirements.txt
python src/main.py --help
```

### Tech Stack
YouTube Data API, Google Search Console API, Web scraping (Reddit/Facebook/Discord), NLP for comment analysis, Video transcription API, SEO optimization tools, Email automation, Analytics dashboard

## <a id="chinese"></a>中文

### 概述
一个内容飞轮系统，通过针对搜索意图而非病毒式传播，将低浏览量的YouTube教程转化为高收益SaaS客户。收集客户痛点，创建针对性教程，并将其优化为永久搜索资产。

### 功能特性
- 从社区、入职邮件、支持工单和YouTube评论中收集客户痛点
- 使用客户原话创建教程，每个视频解决一个具体问题
- 针对Google搜索（非YouTube算法）的SEO优化，包含关键词布局和结构化章节
- 支持工单转公开教程的工作流
- 针对ChatGPT和Google AI模式可见性的AI引用优化
- 从重复客户问题自动生成内容日历
- 专注搜索流量的YouTube分析追踪（63%搜索，26%来自Google）
- 针对细分技术问题的长尾关键词定位

### 安装使用
```bash
pip install -r requirements.txt
python src/main.py --help
```

### 技术栈
YouTube Data API, Google Search Console API, Web scraping (Reddit/Facebook/Discord), NLP for comment analysis, Video transcription API, SEO optimization tools, Email automation, Analytics dashboard
